# FortuneTeller App

## Overview
FortuneTeller is a mobile application developed as part of the Mobile Application Development practical session using React Native and Expo.

## Features
- Simple and user-friendly mobile interface.
- Allows users to interact with the fortune-telling app.
- Displays fortune-related content through the app screens.

## Technologies Used
- React Native
- Expo
- TypeScript
- Visual Studio Code

## How to Run
1. Install Node.js.
2. Install project dependencies using `npm install`.
3. Start the development server using `npx expo start`.
4. Open the application using Expo Go or a compatible Android emulator.
